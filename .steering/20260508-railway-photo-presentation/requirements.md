# 要求内容: 機能7: 路線写真演出

## 対象機能

`docs/product-requirements.md` の「機能7: 路線写真演出」を実装する。

## 受け入れ条件

- [ ] クイズ画面で、問われている路線の写真が表示される (路線ごとに約5枚の写真プールからランダムに1枚選択)
- [ ] 正解・不正解フィードバック画面で、クイズ用と同じ写真プールから写真が表示される
  - feedbackPhotos が空でなければそちらを、空なら quizPhotos から表示継続
- [ ] 路線アンロック演出で、路線ごとに1枚の印象的な写真が表示される
- [ ] 写真は演出用途のみ (ヒントとしては使用しない)
- [ ] 使用できる写真ライセンスは CC0・CC BY・CC BY-SA のみ
- [ ] 写真の下部に帰属表示 (アトリビューション) が常時表示される
  - 表示例: `📷 撮影者名 / Wikimedia Commons / CC BY-SA 4.0`
  - 写真の外側 (下) に小さなグレーテキストで表示する
  - CC0 であっても一貫性のため帰属表示を行う
- [ ] 路線データに `quizPhotos` と `feedbackPhotos` のフィールドを持つ (当初 feedbackPhotos は空配列で運用)

## スコープ

- 対象路線: 中央・総武線各駅停車 (line-sobu)、東武亀戸線 (line-tobu-kamedo)
- 写真は Wikimedia Commons の URL 参照方式
- 帰属表示フォーマットは設計書の仕様通り
