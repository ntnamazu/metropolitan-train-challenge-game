# 要求内容

## 概要

首都圏鉄道マスターのMVPとして、プロダクト要求定義書で定義されたコア機能6つを実装します。クエストモード、クイズ、パズル、難易度システム、デイリーチャレンジ、バッジコレクションの基本機能を提供します。

## 背景

PRDで定義されたコア機能（MVP）を実装することで、以下を実現します:
- ユーザーが鉄道知識を段階的に学べる体験の提供
- クイズとパズルの融合による二段階学習の実現
- 継続的な学習習慣を形成するデイリーチャレンジとバッジシステム
- レベル1（ビギナー）から開始し、段階的に難易度を上げる仕組み

## 実装対象の機能

### 1. 鉄道クエストモード（機能1）
- 各クエストは「クイズで学ぶ」→「パズルで実践」→「チャレンジ」の3ステップで構成
- クエストをクリアすると新しい路線や車両がアンロック
- 初期状態ではレベル1（ビギナー）のクエストのみプレイ可能
- プレイヤーの進捗状況がローカルストレージに保存

### 2. クイズシステム（機能2）
- 4択形式のクイズ出題
- 正解時に豆知識を表示
- 不正解でも正解と解説を表示
- カテゴリ: 駅名、路線名、所要時間、乗り換え、会社の特色など
- 各クエストに3-5問のクイズを含む

### 3. 経路選択パズル（機能3）
- 路線図上で駅をクリック/タップして経路を選択
- 出発駅と目的駅が指定される
- 時間制限（30秒-1分）を設定
- 正しい経路判定と結果表示
- 駅数、乗り換え回数などの制約条件を提示

### 4. 段階的難易度システム（機能4）
- レベル1（ビギナー）: JR中央・総武線各駅停車、東武亀戸線のみプレイ可能
- レベル1→2のアンロック条件: レベル1のクエストを3つ以上クリア
- プレイヤーの現在レベルと進捗を管理
- レベルアップ時の報酬とアンロック処理

### 5. デイリーチャレンジ（機能5）
- 毎日異なる路線のクエストを提示
- 1日1回までプレイ可能
- クリアでログインボーナス（ポイントやバッジ）獲得
- 毎日午前0時にリセット

### 6. 実績バッジ・コレクション（機能6）
- 特定条件達成でバッジ獲得（例: 「山手線マスター」）
- 車両カード図鑑（レア度別）
- 獲得したバッジとカードをコレクション画面で確認
- 未獲得バッジの条件表示

## 受け入れ条件

### 鉄道クエストモード
- [ ] クエストが「クイズ」→「パズル」→「チャレンジ」の3ステップで構成されている
- [ ] クエストクリア時に新しい路線や車両がアンロックされる
- [ ] 初期状態ではレベル1のクエストのみが利用可能
- [ ] プレイヤーの進捗がローカルストレージに保存される

### クイズシステム
- [ ] 4択形式でクイズが出題される
- [ ] 正解選択時に豆知識が表示される
- [ ] 不正解時にも正解と解説が表示される
- [ ] 各クエストに3-5問のクイズが含まれる

### 経路選択パズル
- [ ] 路線図が表示され、駅をクリック/タップで経路選択できる
- [ ] 出発駅と目的駅が指定される
- [ ] 時間制限が設定される（30秒-1分）
- [ ] 正しい経路の判定が動作する
- [ ] 駅数、乗り換え回数などの制約条件が表示される

### 段階的難易度システム
- [ ] レベル1では指定された路線のみプレイ可能
- [ ] レベル1のクエストを3つクリアするとレベル2がアンロック
- [ ] プレイヤーの現在レベルが管理される
- [ ] レベルアップ時に報酬が付与される

### デイリーチャレンジ
- [ ] 毎日異なるクエストが提示される
- [ ] 1日1回のみプレイ可能
- [ ] クリア時にボーナスポイントが付与される
- [ ] 毎日午前0時にリセットされる

### 実績バッジ・コレクション
- [ ] 特定条件達成でバッジが獲得できる
- [ ] 車両カード図鑑が存在する
- [ ] コレクション画面でバッジとカードを確認できる
- [ ] 未獲得バッジの条件が確認できる

## 成功指標

- レベル1のクエストが3つ以上プレイ可能である
- クイズ、パズル、チャレンジの各ステップが正常に動作する
- プレイヤーデータが永続化され、リロード後も保持される
- デイリーチャレンジが日付ごとに正しく機能する
- バッジとコレクションが正しく表示される

## スコープ外

以下はこのフェーズでは実装しません:

- レベル2以降の詳細なクエストデータ（レベル1のみ実装）
- 週替わりイベント（Post-MVP機能）
- ランキングシステム（Post-MVP機能）
- 相互直通パズル、時刻表パズル、最適化パズル（Post-MVP機能）
- ユーザー登録・ログイン機能（MVPではローカルストレージのみ）
- マルチプレイヤー機能
- AR/VR機能
- ソーシャルメディア連携
