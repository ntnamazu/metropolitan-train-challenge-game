# 実装設計: README.md の内容更新

## 変更対象

- `README.md`

## 設計方針

既存の README を完全に書き換え、以下の構成で作成する:

1. **プロジェクト概要** - 名称・コンセプト・ビジョン
2. **技術スタック** - 主要ライブラリとバージョン
3. **開発環境のセットアップ** - Dev Container を使った手順
4. **npm スクリプト一覧** - dev / build / test / lint / typecheck など
5. **ディレクトリ構造** - 簡易版
6. **ドキュメント** - docs/ 内のドキュメント一覧

## 情報ソース

- `docs/product-requirements.md`: プロジェクト概要・コンセプト
- `docs/architecture.md`: 技術スタック
- `docs/repository-structure.md`: ディレクトリ構造
- `package.json`: スクリプト一覧・依存関係バージョン
