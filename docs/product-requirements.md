# プロダクト要求定義書 (Product Requirements Document)

## プロダクト概要

### 名称
**首都圏鉄道マスター** - 楽しく学べる鉄道知識ゲーム

### プロダクトコンセプト
- **クイズとパズルの融合**: 鉄道に関する知識をクイズで学び、パズルで実践する二段階学習
- **段階的な路線アンロック**: 簡単な山手線から始まり、複雑な相互直通運転まで段階的に難易度が上がる
- **実在する豊富な路線網**: 首都圏のJR線と私鉄線(東急、小田急、京王、西武、東武、京急、京成、東京メトロなど)を網羅

### プロダクトビジョン
10歳程度の子供が、楽しみながら首都圏の鉄道に関する知識を身につけられるブラウザゲームを提供する。
クイズで鉄道の基礎知識を学び、パズルで実際の経路選択や乗り換えを体験することで、実用的な知識を習得できる。
段階的な難易度設計により、初心者からマニアまで長く楽しめる学習体験を実現する。
デイリーチャレンジやランキングシステムにより、継続的な学習習慣を形成し、鉄道に対する知識欲を喚起する。

### 目的
- 首都圏の鉄道に関する知識欲を喚起する
- 楽しみながら実用的な鉄道知識を学べる体験を提供する
- 路線図、駅名、乗り換え、時刻表などの実践的な知識を習得できるようにする
- 継続的な学習習慣を形成し、段階的にスキルアップできるようにする

## ターゲットユーザー

### プライマリーペルソナ: 田中健太(10歳、小学4年生)
- 鉄道に興味があり、電車を見るのが好き
- ゲームが好きで、スマートフォンやPCでブラウザゲームをプレイする
- 両親と一緒に電車で出かけることが多く、路線図を見るのが楽しい
- 現在の課題: 鉄道の知識をもっと深めたいが、参考書は難しくて退屈
- 期待する解決策: ゲーム感覚で楽しく鉄道の知識を学べるツール
- 1日の典型的な使い方: 学校から帰宅後、15-30分程度ゲームをプレイし、新しい路線や駅を学ぶ

### セカンダリーペルソナ: 保護者(35-45歳)
- 子供の学習をサポートしたい
- 安全で教育的なコンテンツを求めている
- ゲームを通じた学習効果を期待
- 期待する価値: 子供が楽しみながら実用的な知識を身につけられること

## 成功指標(KPI)

### プライマリーKPI
- **日次アクティブユーザー(DAU)**: 500人(6ヶ月後)
  - 測定方法: ログイン数とゲームプレイ開始数
- **平均プレイ時間**: 1セッションあたり15分以上
  - 測定方法: セッション開始から終了までの時間
- **クエスト完了率**: 60%以上
  - 測定方法: 開始したクエストのうち、最後まで完了した割合
- **継続率(7日後リテンション)**: 40%以上
  - 測定方法: 初回プレイから7日後も再訪したユーザーの割合

### セカンダリーKPI
- **路線アンロック率**: ユーザーあたり平均5路線以上(3ヶ月後)
  - 測定方法: 各ユーザーがアンロックした路線数の平均
- **クイズ正解率**: 70%以上
  - 測定方法: 全クイズの正解数 / 全回答数
- **デイリーチャレンジ参加率**: 30%以上
  - 測定方法: デイリーチャレンジに参加したユーザー / DAU

## 機能要件

### コア機能(MVP)

#### 機能1: 鉄道クエストモード

**ユーザーストーリー**:
プレイヤーとして、鉄道に関する知識を段階的に学ぶために、クエスト形式のミッションをクリアしたい

**受け入れ条件**:
- [ ] 各クエストは「クイズで学ぶ」→「パズルで実践」→「チャレンジ」の3ステップで構成される
- [ ] クエストをクリアすると新しい路線や車両がアンロックされる
- [ ] 初期状態ではレベル1(ビギナー)のクエストのみプレイ可能
- [ ] プレイヤーの進捗状況(クリア済みクエスト、アンロック済み路線)がローカルストレージに保存される

**優先度**: P0(必須)

#### 機能2: クイズシステム

**ユーザーストーリー**:
プレイヤーとして、鉄道に関する基礎知識を学ぶために、4択形式のクイズに答えたい

**受け入れ条件**:
- [ ] 各クイズは4択形式で出題される
- [ ] 正解を選択すると、豆知識が表示される
- [ ] 不正解の場合でも、正解と解説が表示される
- [ ] クイズのカテゴリ: 駅名、路線名、所要時間、乗り換え、会社の特色など
- [ ] 各クエストには3-5問のクイズが含まれる

**優先度**: P0(必須)

#### 機能3: 経路選択パズル

**ユーザーストーリー**:
プレイヤーとして、学んだ知識を実践するために、路線図上で駅をタップして経路を選びたい

**受け入れ条件**:
- [ ] 路線図が表示され、駅をクリック/タップして経路を選択できる
- [ ] 出発駅と目的駅が指定される
- [ ] 時間制限(30秒-1分)が設定される
- [ ] 正しい経路を選択すると成功、間違った経路では失敗と表示される
- [ ] 駅数、乗り換え回数などの条件が提示される

**優先度**: P0(必須)

#### 機能4: 段階的難易度システム

**ユーザーストーリー**:
プレイヤーとして、自分のレベルに合った難易度でプレイするために、段階的にアンロックされる路線と問題に挑戦したい

**受け入れ条件**:
- [ ] レベル1(ビギナー): JR中央・総武線各駅停車、東武亀戸線のみプレイ可能
- [ ] レベル2(中級者): 首都圏主要JR線、主要私鉄(東急、小田急など)がアンロック
- [ ] レベル3(上級者): 相互直通運転を含む複雑な路線がアンロック
- [ ] レベル4(マニア): 全路線網がアンロック
- [ ] 前のレベルのクエストを一定数クリアすると次のレベルがアンロックされる

**レベルアップ条件**:
- レベル1→2: レベル1のクエストを3つ以上クリア
- レベル2→3: レベル2のクエストを5つ以上クリア
- レベル3→4: レベル3のクエストを8つ以上クリア

> **注記**: 上記の数値はゲームバランスを考慮した暫定値です。ユーザーテスト後に調整が必要になる可能性があります

**優先度**: P0(必須)

#### 機能5: デイリーチャレンジ

**ユーザーストーリー**:
プレイヤーとして、毎日新しい挑戦を楽しむために、日替わりのクエストに挑戦したい

**受け入れ条件**:
- [ ] 毎日異なる路線のクエストが提示される
- [ ] デイリーチャレンジは1日1回までプレイ可能
- [ ] クリアするとログインボーナス(ポイントやバッジ)が獲得できる
- [ ] 毎日午前0時にリセットされる

**優先度**: P1(重要)

#### 機能6: 実績バッジ・コレクション

**ユーザーストーリー**:
プレイヤーとして、自分の達成度を可視化するために、バッジや車両カードを集めたい

**受け入れ条件**:
- [ ] 特定の条件を達成するとバッジが獲得できる(例: 「山手線マスター」「乗り換え名人」)
- [ ] 車両カード図鑑があり、レア度別に分類される
- [ ] 獲得したバッジとカードがコレクション画面で確認できる
- [ ] 未獲得のバッジの条件が確認できる

**優先度**: P1(重要)

### 将来的な機能(Post-MVP)

#### 週替わりイベント

特定のテーマに沿った期間限定クエスト(例: 「新幹線週間」「私鉄マスターチャレンジ」)

**優先度**: P2(できれば)

#### ランキングシステム

友達やクラスメイトとスコアを競えるランキング機能

**優先度**: P2(できれば)

#### 相互直通パズル

複雑な相互直通運転のルートを辿るパズル(例: 和光市から横浜まで乗り換えなし)

**優先度**: P2(できれば)

#### 時刻表パズル

時刻表を読み解いて、指定時刻に目的地に到着するルートを選ぶパズル

**優先度**: P2(できれば)

#### 最適化パズル

複数の乗客をそれぞれの目的地に最短時間で届けるパズル、遅延発生時の代替ルート選択

**優先度**: P2(できれば)

## 非機能要件

### パフォーマンス
- **ページ読み込み時間**: 初回読み込み3秒以内、2回目以降1秒以内(平均的なブロードバンド環境で)
- **クイズ回答後のフィードバック表示**: 500ms以内
- **パズル操作のレスポンス時間**: タップ/クリックから100ms以内

### ユーザビリティ
- **初回プレイでの学習時間**: 新規ユーザーが3分以内に基本操作を習得できる
- **UI**: 10歳の子供が直感的に操作できるシンプルなデザイン
- **アクセシビリティ**: 色覚特性に配慮したカラースキーム、フォントサイズの調整機能

### 信頼性
- **データ保存**: プレイヤーの進捗状況はローカルストレージに自動保存され、ブラウザを閉じても保持される
- **エラーハンドリング**: クエスト途中でエラーが発生した場合、最後のチェックポイントから再開できる
- **稼働率**: 99%以上(月間)

### セキュリティ
- **個人情報の取り扱い**: ユーザー登録は不要、個人情報は収集しない
- **HTTPS**: 全通信をHTTPSで暗号化
- **XSS対策**: ユーザー入力のサニタイゼーション

### スケーラビリティ
- **ユーザー数**: 同時接続1000人まで対応
- **路線データ拡張**: 新しい路線や駅を容易に追加できるデータ構造
- **クエスト追加**: 新しいクエストを簡単に追加できる仕組み

### ブラウザ対応
- **対応ブラウザ**: Chrome、Firefox、Safari、Edgeの最新版および1つ前のバージョン
- **モバイル対応**: スマートフォンとタブレットでのプレイに対応(レスポンシブデザイン)

## スコープ外

明示的にスコープ外とする項目:
- ユーザー登録・ログイン機能(MVPではローカルストレージのみ)
- マルチプレイヤー機能(ランキングはPost-MVP)
- リアルタイムの運行情報連携
- 首都圏以外の鉄道路線(関西、中部などは将来的に検討)
- AR/VR機能
- ソーシャルメディア連携(シェア機能など)
- 課金・マネタイズ機能(MVPでは無料提供)
